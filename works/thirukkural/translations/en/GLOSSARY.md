# Controlled English Glossary — Thirukkural: Kalaignar's Commentary

This glossary records **editorial defaults for the project translation**. It is not a claim that each Tamil term has one fixed English equivalent in every context.

When context requires a different rendering, preserve the source meaning and record the choice during review rather than forcing the default mechanically.

| Tamil | Default English range | Usage note |
|---|---|---|

| ஒழுக்கம் | conduct; good conduct; moral discipline | `conduct` is often safest; use stronger moral wording only where source context supports it. |
| ஒழுகலாறு | manner of conduct | Used analytically by Nannan in scans 13–14. |

| நடுவுநிலைமை | impartiality; even-handedness | Avoid `neutrality` where the sense is justice/fair dealing. The scan-30 source gloss `பொதுவாக இருத்தல்` is separately retained as **Being common to all**. |
| நன்றி | gratitude; benefit; good done | Meaning varies by construction; Part 002 also uses it as a concluding section heading meaning gratitude/acknowledgement. |

## Translation-note policy

Add a translation note only when it helps preserve fidelity, for example:

- a Tamil term has two materially different plausible English senses;
- an unusual source form affects interpretation;
- a compressed Kural requires an interpretive syntactic choice;
- a source-specific title differs from a more familiar title in other editions.

Do **not** add notes merely to teach general Thirukkural background or summarize other commentators.

## Glossary governance

1. Add new recurring terms when they first become important.
2. Do not change a controlled heading casually after multiple pages use it.
3. If a heading/core term changes, record the reason in the relevant part review and update all affected English files.
4. Keep published-source English terminology separate if an official/published English edition is supplied later.
5. The Tamil scan and audited Tamil transcription always outrank this glossary.
