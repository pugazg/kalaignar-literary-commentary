## Structural-term reconciliation

## Recurring terminology reconciliation

- `கள் / மது` → **liquor / alcoholic drink / intoxication** according to grammar and context; chapter 93 remains **Abstaining from Liquor**.
- `சூது` → **Gambling / gambling**. Preserve stakes, loss and the fish/hook imagery rather than abstracting the discussion into generic vice language.
- `மருந்து / மருத்துவம்` → **Medicine / medicine / treatment / medical method** according to context. Kural 948 retains Kalaignar's explicit extension from bodily disease to **social disease**.
- `குடி / குலம் / குடிமக்கள்` remains context-sensitive: **lineage / family line / citizens**. Chapter 96 is **Nobility**, while Kural 953 commentary explicitly remains **truthful citizens**.
- `மானம்` → **Honour / honour / sense of honour**. Preserve shame, dignity, self-respect and refusal of servile submission where Kalaignar supplies them.
- `பெருமை` → **Greatness / greatness**. Kalaignar's distinction between position and character remains explicit.
- `சான்றாண்மை / சால்பு` → **Exemplary Character / exemplary character / character / excellence** according to syntax. This remains distinct from chapter 100 `பண்புடைமை` → **Good Character**.
- `பண்புடைமை / பண்பு` → **Good Character / good character / character**.
- `நன்றியில் செல்வம்` → **Wealth Without Benefit**. The ordinary `நன்றி` → gratitude control is not mechanically imported into this compound title.
- `விலைமகளிர்` remains **women for hire**, preserving the project's earlier controlled social/gender-specific wording.
