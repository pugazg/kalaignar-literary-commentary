## தற்போதைய முன்னேற்றம்

ஸ்கேன் 7 (`முகவுரை`) மூலப் படத்துடன் எழுத்துக்கு எழுத்து ஒப்பிட்டு `verified` செய்யப்பட்டது. முதல் சுற்றில் தவறாகப் பதிவான `ஐம்பது நான்கு`, `பொருளையொன்னியில்` ஆகிய வாசிப்புகள் ஸ்கேனில் தெளிவாகத் தெரியும் `ஐம்பத்து நான்கு`, `பொருளையன்றி` எனத் திருத்தப்பட்டன. இது மொழிச்சீரமைப்பு அல்ல; இந்த exact scan-இன் visual reread அடிப்படையிலான transcription correction.

ஸ்கேன் 8-க்கு **300-DPI high-resolution visual review** நடத்தப்பட்டது. தலைப்பு **`முகவுரையின் ஒரு முன்னுரை!`** எனத் தெளிவாக வாசிக்கப்படுகிறது; இறுதி கையொப்பமும் **27/12/2007** தேதியும் தெளிவாக உள்ளன. ஆனால் தொடர்ச்சியான உட்பகுதி கையெழுத்தின் பல சொற்கள் source-faithful ஆக உறுதிப்படுத்த முடியாததால், அவை context மூலம் ஊகித்து நிரப்பப்படவில்லை; பக்கம் `partial` ஆகவே பாதுகாக்கப்படுகிறது.

ஸ்கேன் **9–12**-இல் உள்ள `பேராசிரியரின் அணிந்துரை` முழுவதும் source scan-உடன் எழுத்துக்கு எழுத்து ஒப்பிடப்பட்டு `verified` செய்யப்பட்டது. கவிதை வரி முறிவுகள், நிறுத்தற்குறிகள், சந்தி/சொல் இணைப்புகள் மற்றும் மூலத்தில் காணப்படும் அசாதாரண வடிவங்கள் மாற்றமின்றி பாதுகாக்கப்பட்டன. ஸ்கேன் 9-இல் first-pass `செல்வமீனும்` என்பது exact scan-இல் தெளிவாகக் காணப்படும் **`செல்வமினும்`** எனத் திருத்தப்பட்டது. அதே பக்கத்தின் `மநுவாதிக்கு`, `உற்றிடுமியற்கைச்`, `‘தொழல்’`, `வான்றோய் முகில்பொழி தூநீர் அனையதாய்` போன்ற source-supported வடிவங்கள் சீர்திருத்தப்படாமல் வைக்கப்பட்டன. ஸ்கேன் 10–12-இன் first-pass wording visual verification-இல் உறுதிப்படுத்தப்பட்டதால் கூடுதல் textual correction தேவைப்படவில்லை.

ஸ்கேன் **13–16**-இல் பேராசிரியர் மா. நன்னனின் `மதிப்புரை` source scan-உடன் character-by-character verify செய்யப்பட்டது. `தேவை`, `வழிபாடு`, `பெண்வழிச் சேறல்` தொடக்கம் மற்றும் எண்ணிட்ட விளக்கங்கள் அனைத்தும் first-pass transcription-ஐ உறுதிப்படுத்தின; wording correction எதுவும் தேவைப்படவில்லை. குறிப்பாக source-sensitive வடிவங்களான `அய்ந்து`, `ஈகையறம்`, `ஒழுகலாறு`, `மன்பதையைச்`, `அவைகளை யெல்லாம்`, `உறுதிப்படுத்தப் படாமையால்`, `அக் கருத்துக்காட்பட்ட` ஆகியவை exact scan-இல் மீண்டும் உறுதிப்படுத்தப்பட்டு அப்படியே பாதுகாக்கப்பட்டன.

ஸ்கேன் 17–20-க்கான முதல் சுற்று transcription மூலப் படங்களை நேரடியாக வாசித்து, OCR-ஐ உதவிக்கருவியாக மட்டும் பயன்படுத்தி அமைக்கப்பட்டுள்ளது. OCR வெளியீடு source authority ஆகக் கருதப்படவில்லை. வரலாற்றுச் சொல்வடிவம், சந்தி, அச்சுப் பிழை எனத் தோன்றும் வடிவம், குறள் உரை ஆகியவை இணையம் அல்லது வேறு பதிப்பின் அடிப்படையில் அமைதியாகச் சீர்திருத்தப்படவில்லை.
