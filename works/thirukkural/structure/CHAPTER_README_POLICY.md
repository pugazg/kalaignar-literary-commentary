# அதிகாரம் README policy

Each of the 133 அதிகாரம் directories in `structure/` is a semantic navigation node.

Every chapter README records:

- பால்
- இயல்
- அதிகாரம் number and title
- its deterministic ten-Kural range: `(chapter − 1) × 10 + 1` through `chapter × 10`
- links back to the canonical Tamil physical-page archive and released English physical-page archive

## Archival boundary

The chapter-to-Kural range is semantic metadata. The repository's canonical source transcription remains `../../pages/` (from the work root), and released English remains `../../translations/en/pages/`. These chapter READMEs do **not** claim an exact physical scan-page boundary unless that boundary has been independently verified from the source scan/page records. This prevents semantic navigation from silently becoming invented scan pagination.

Chapter titles follow this project's established structure, including chapter 1 `வழிபாடு`.
