3. “அரிபெய் சிலம்பின் ஆம்பலந் தொடலை,
அரம்போழ் அவ்வளைப் பொலிந்த முன்கை,
இழையணி பணைத்தோள், ஐயை தந்தை,
மழைவளம் தரூஉம் மாவண் தித்தன்....”

(அகநானூறு : பாடல் : 6
பாடியவர் : பரணர்)

4. “மாவண் தித்தன் வெண்ணெல் வேலி
உறந்தை அன்ன உரைசால் நன்கலம்
கொடுப்பவும் கொளாஅ நெடுந்தகையவனே....”

(புறநானூறு : பாடல் : 352
பாடியவர் : பரணர்)

5. “சிற்றில் நற்றூண்பற்றி, நின்மகன்
யாண்டுளனோ? என வினவுதி; என்மகன்
யாண்டு உளன் ஆயினும் அறியேன்; ஒரும்
புலி சேர்ந்து போகிய கல்அளை போல,
ஈன்ற வயிறோ இதுவே;
தோன்றுவன் மாதோ, போர்க்களத்தானே!”

(புறநானூறு : பாடல் : 86
பாடியவர் : காவற்பெண்டு)

## பொருள் விளக்கம் :

வெண்கோடு = வெளிய சங்கு. செல்லாநல்லிசை = கெடாத
நற்புகழ். அரிபெய் = பரல்கள் இடப்பட்ட.
தொடலை = தொடுக்கப்பட்ட மாலை. அரம்போழ் = அரமிட்டு
அறுத்த. பணை = மூங்கில். மாவண் = சிறந்த கொடைத்தன்மை
கொண்ட. வெண்ணெல்வேலி = நெல்விளையும் வயல்களை
வேலியாகப் பெற்ற. நன்கலம் = அணிகலன்.
கல்அளை = மலைக் குகை.
