மண்டு அமர்ப் பரிக்கும் மதனுடை நோன்தாள்  
விழுமியோன் பெறுகுவன் ஆயின், தாழ்நீர்  
அறுகய மருங்கின் சிறுகோல் வெண்கிடை  
என் றூழ் வாடுவறல் போல, நன்றும்  
நொய்தால் அம்ம தானே - மையற்று  
விசும்புஉற ஓங்கிய வெண்குடைய  
முரசுகெழு வேந்தர் அரசுகெழு திருவே."  

\*

(புறநானூறு பாடல் : 73,75  
பாடியவர் : சோழன் நலங்கிள்ளி)

## பொருள் விளக்கம் :

மடவோன் = அறிவற்றவன். துஞ்சுபுலி = தூங்கும் புலி.  
சிதடன் = குருடன். கழை = மூங்கில். மைந்துடை = வலிமை  
உடைய. வன்றிணி = பலமும் திண்மையும் உடைய.  
ஒல்லா முயக்கு = அன்பிலா புணர்ச்சி.  
பால்தர வந்த பழவிறல் தாயம் = விதிமுறைப்படி வந்த  
(வாரிசு) அரசுரிமை. கூரில் ஆண்மை = ஆண்மை மிகக்  
கொண்டிராத. மண்டுஅமர்=பெரும்போர்.  
மதன் = மன எழுச்சி. பரிக்கும் = (எதிர்நின்று) தாங்கிடும்.  
அறுகயம் = வற்றிய குளம். கிடை = நெட்டி.  
நொய்து = எளிதானது.
