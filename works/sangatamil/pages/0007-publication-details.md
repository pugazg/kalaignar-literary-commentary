# நூல் அளவை

- தலைப்பு : சங்கத் தமிழ்.
- ஆசிரியர் : கலைஞர் மு. கருணாநிதி.
- பொருள் : இலக்கியம் (சங்கத் தமிழுக்கு, எளிய நடையில் விளக்கக் கவிதை வரிகள்)
- வெளியீட்டகம் : ராக்போர்ட் பப்ளிகேஷன்ஸ் (பி) லிட். - சென்னை - 600 083.
- வெளியீடு : 4.
- பதிப்பு : ஒன்று.
- தாள் : மாப் லித்தோ.
- அளவு : 14 x 21½ செ.மீ.
- படிகள் : 3,000.
- காலம் : ஆகஸ்ட் 1987.
- விலை : ரூ. 125|- (ரூபாய் நூற்று இருபத்தி ஐந்து)
- எழுத்து : 18 புள்ளி.
- ஓவியங்கள் : கோபுலு - ஜெயராஜ் - மாருதி / உமாபதி - மருது.
- தலைப்புகள் : ஓவியக் கவிஞர் அமுதோன்.
- ஒளி அச்சுக் கோர்வை : காந்தகம் - சென்னை-2.
- அச்சிட்டோர் : சீனிவாஸ் பைன் ஆர்ட்ஸ் - சிவகாசி.
