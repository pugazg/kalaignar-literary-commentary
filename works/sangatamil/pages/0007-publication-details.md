# நூல் அளவை

- தலைப்பு : சங்கத் தமிழ்.
- ஆசிரியர் : கலைஞர் மு. கருணாநிதி.
- பொருள் : இலக்கியம் (சங்கத் தமிழுக்கு, எளிய நடையில் விளக்கக் கவிதை வரிகள்)
- வெளியிட்டகம் : ராக்போர்ட் பப்ளிகேஷன்ஸ் (பி) லிட். - சென்னை - 600 083.
- வெளியீடு : 4.
- பதிப்பு : ஒன்று.
- அளவு : 14 x 21½ செ.மீ.
- பிரதிகள் : 3,000.
- காலம் : ஆகஸ்ட் 1987.
- விலை : ரூ. 125/- (ரூபாய் நூற்று இருபத்தைந்து)
- எழுத்து : 18 புள்ளி.
