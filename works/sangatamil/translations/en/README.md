# Sangatamil — English project translation

This directory contains the **project-created maintained English translation layer** for the closed Tamil archival workspace of Kalaignar M. Karunanidhi's `சங்கத் தமிழ்`.

This is **not** an official or publisher-issued English edition.

Every English page must carry:

```yaml
translation_type: "project_translation"
```

## Tamil authority and limitation

Normal English work uses the canonical Tamil page records under `../../pages/`, together with the closed section/provenance/navigation layers.

The Tamil archive is structurally, physically, sectionally, provenance-wise, metadata-wise and navigationally closed through Gates A–I. Gate C2 also adjudicated all **140/140 recorded Gate-C discrepancies**.

However, the corpus is **not claimed to have received a fresh exhaustive word-for-word reread of every source token**. Final Tamil page status remains:

- `verified` — 43
- `needs-review` — 453
- `partial` — 1 (scan 8 handwritten `முன்னுரை`, description-only)

English release status therefore means **reviewed against the maintained canonical Tamil record**, not that the underlying Tamil scan has become exhaustively word-for-word verified.

The original Tamil scan remains the ultimate source authority when a genuine source/fidelity problem is discovered. Do not reopen the closed Tamil layer merely for translation polishing.

## Maintained-English workflow

**Tamil archival closure → English draft → English source-check → glossary reconciliation → editorial review → whole-volume/section-level review → release report → release-ready.**

The methodology is adapted from the maintained-English Kuraloviyam workflow.

Normal page-batched cadence: **37 consecutive physical scans per iteration**, unless the user explicitly changes it. A final remainder may be shorter.

## Source discipline

Do not silently import:

- a published English Sangam translation;
- another commentator's rendering;
- web text;
- remembered conventional translations;
- external modernized Tamil;
- reconstructed wording for scan 8 handwriting.

Translate only the maintained Tamil archive. Preserve the work's own order, quoted Sangam verse blocks, prose commentary, source notes, poet/work/poem-number metadata, visual descriptions and cross-page continuities.
