# Controlled English Glossary — Sangatamil

This glossary records editorial defaults for the **project-created maintained English translation** of `சங்கத் தமிழ்`.

It starts deliberately small. Add terms only when they are evidenced in the active Sangatamil source.

Defaults are context-aware; do not force one English equivalent mechanically.

## Work and archival terms

| Tamil | Default English | Editorial note |
|---|---|---|
| சங்கத் தமிழ் | Sangatamil | Retain the work title as the project title. |
| கலைஞர் | Kalaignar | Retain the established title/name. |
| கலைஞர் மு. கருணாநிதி | Kalaignar M. Karunanidhi | Default author form. |
| முன்னுரை | Preface | General source heading; scan 8 body is handwritten and description-only. |
| பொருள் விளக்கம் | Explanation of meaning | Preserve as a source-labelled explanatory block; context may permit “Meaning” where layout requires brevity. |
| பாடல் | poem / verse | Use according to source context; preserve source numbering. |
| புலவர் | poet | Use for poet attribution unless a more specific source role is present. |
| தோழி | friend / confidante | Context-sensitive in classical love poetry; do not mechanically flatten relationship nuance. |
| தலைவி | heroine / lady / female lover | Context-sensitive; choose from the narrative role, not mechanically. |
| தலைவன் | hero / man / male lover | Context-sensitive; choose from the narrative role, not mechanically. |

## Sangam source titles

Add each anthology/work title when it is first encountered in the maintained translation. Prefer consistent transliteration unless an established project English form is explicitly adopted.

## Names and literary terms

Record recurring personal names, place names, dynastic titles, flora/fauna terms and classical literary concepts as they are encountered.

## Rule

No published English Sangam translation, web translation or external commentary may be used as a silent wording source.
